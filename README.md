\# NGO Connect



NGO Connect is a web-based platform designed to connect NGOs, volunteers, and users through a simple and interactive interface.



\## Features



\- User login and registration

\- NGO-related information and interaction

\- Dashboard interface

\- Backend API using Node.js and Express

\- MongoDB database integration

\- AI-related functionality using Google Gemini API



\## Technologies Used



\### Frontend

\- HTML

\- CSS

\- JavaScript



\### Backend

\- Node.js

\- Express.js

\- MongoDB

\- Google Gemini API
